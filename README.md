# Predictor-Precios-Casas
Proyecto de desarrollo web, en el cual se enfocara crear un sitio web que contenga un modelo predictorio de precio de casas condierando unua seria de variables

- Nota: dentro del sitio web en la carpeta static, hay una carpeta destinada para almacenar el modelo entrenado, debido a que pesaba mas de lo que github permitia, se tuvo que elimar el archivo, el codigo del entrenamiento esta guardado en la carpte "modelo"
